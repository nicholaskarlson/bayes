# Unit 7 fictional case provenance

The 36-row file is original authored teaching data, generated exactly by `scripts/generate_unit07.py`. It is neither a transformed real dataset nor the twelve Unit 2/3 volunteers. IDs and outcome positions are fixed by the author; the route was not randomized. No hidden truth, institutional record, service-contact log or campus sampling frame exists. The code's fixed zero poster reports is a pedagogical sparse cell, not empirical evidence that a programme or recruitment route works. The data dictionary defines a reported binary event; a `0` does not establish no need or no actual contact.

The model and reference summaries are in `model-specs/unit07_proportions.json` and `expected-results/unit07_proportions.json`. `scripts/analyze_unit07.py` computes exact Beta marginals and deterministically integrates their contrast. `make verify` checks the public Python outputs and anchors; `make r-audit` supplies an independent base-R integration route. Stated prior predictive and posterior predictive probabilities are model implications, not held-out prediction. The counterfactual effect of a recruitment route, true contact prevalence, population coverage and missingness behavior are unidentified by these fictional convenience records.
